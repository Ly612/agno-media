# 本地启动指南（后端 + 前端）

本指南说明如何在本地同时启动 **后端 agno-media** 与 **前端 AgentUI**，跑通完整的图形聊天界面。

- 后端 `agno-media`：你们团队开发的 Agent 服务（本仓库），提供 API，运行在 `http://localhost:7777`。
- 前端 `agent-ui`：官方开源图形界面（独立项目，无需修改），运行在 `http://localhost:3000`。

> 两个服务需**同时运行**，各占一个终端窗口。若只调 API、不需要界面，可只启动后端。

---

## 一、环境要求

| 依赖 | 版本 | 用途 |
|------|------|------|
| Python | >= 3.10 | 后端 |
| [uv](https://docs.astral.sh/uv/) | 最新 | 后端包管理（推荐，也可用 pip） |
| Node.js | >= 18 | 前端 |
| npm | 随 Node.js | 前端包管理 |

检查是否已安装：

```powershell
python --version
uv --version
node --version
npm --version
```

---

## 二、启动后端（agno-media）

### 1. 克隆项目

```powershell
git clone https://github.com/Ly612/agno-media.git
cd agno-media
```

### 2. 创建虚拟环境并安装依赖

```powershell
uv venv --python 3.12
.venv\Scripts\Activate.ps1
uv pip install -U "agno[os,sqlite]" openai pyyaml python-dotenv
```

> 未安装 uv 时改用 pip：
> ```powershell
> python -m venv .venv
> .venv\Scripts\Activate.ps1
> pip install "agno[os,sqlite]" openai pyyaml python-dotenv
> ```

### 3. 配置 token

`.env` 不在仓库里，需自行创建（存放网关 token）：

```powershell
Copy-Item .env.example .env
```

编辑 `.env`，把占位符换成真实网关 token：

```
AI_API_KEY=你的真实token
```

> 网关地址与模型在 `config.yaml` 的 `ai` 段（默认已填好，通常无需改动）。

### 4. 启动后端服务

```powershell
python main.py
```

启动成功后：

- 服务地址：<http://localhost:7777>
- API 文档（Swagger）：<http://localhost:7777/docs>

**保持此终端窗口开启**，不要关闭。

---

## 三、启动前端（AgentUI，可选）

前端是官方开源项目，与本仓库无关。**在本仓库之外**另找一个目录克隆。

> 前端只需克隆和安装一次，以后重启只跑 `npm run dev` 即可。

### 1. 克隆前端项目

```powershell
git clone https://github.com/agno-agi/agent-ui.git
cd agent-ui
```

> 若直连 GitHub 不稳定，用镜像克隆：
> ```powershell
> git clone https://gitclone.com/github.com/agno-agi/agent-ui.git
> cd agent-ui
> ```

### 2. 安装依赖

```powershell
npm install
```

### 3. 启动前端服务

```powershell
npm run dev
```

启动成功后打开：<http://localhost:3000>

---

## 四、连接前后端

1. 确保**后端已在 7777 运行**（见第二节）。
2. 浏览器打开前端 <http://localhost:3000>。
3. 在左侧边栏的 **endpoint** 输入框填入后端地址：`http://localhost:7777`（通常默认已是此值）。
4. 顶部选择 Agent（如 **Web Agent** / **Media Agent**），即可开始对话。

架构示意（全程本地，不经过官方云端）：

```
浏览器
  │
  ▼
前端 AgentUI (localhost:3000)   ← 官方开源前端
  │  调用 REST API
  ▼
后端 AgentOS (localhost:7777)   ← 本仓库 agno-media
  │  模型请求
  ▼
第三方网关 gate.aidingqing.com/v1
```

## 五、日常重启（依赖已装过）

**终端 1 — 后端**

```powershell
cd agno-media
.venv\Scripts\Activate.ps1
python main.py
```

**终端 2 — 前端**

```powershell
cd agent-ui
npm run dev
```

## 六、常见问题

| 现象 | 原因与解决 |
|------|------------|
| 启动报 **401 / 认证失败** | `.env` 里的 `AI_API_KEY` 未填或无效，检查 token。 |
| 启动报 **404 / 找不到接口** | `config.yaml` 的 `ai.base_url` 应为 `https://gate.aidingqing.com/v1`（到 `/v1` 为止，勿带 `/chat/completions`）。 |
| **端口被占用** | 后端改 `config.yaml` 的 `server.port`；或关掉占用 7777 / 3000 的进程。 |
| **前端连不上后端** | 确认后端已在 7777 运行，且前端 endpoint 填 `http://localhost:7777`。 |
| **git clone 前端失败（连接重置）** | 直连 GitHub 不稳，改用镜像：`git clone https://gitclone.com/github.com/agno-agi/agent-ui.git`。 |
| **npm install 很慢** | 可切换国内镜像：`npm config set registry https://registry.npmmirror.com`。 |
